# GPU Shield 1.1

Приложение для Windows 11 x64: контролирует температуру NVIDIA GPU и выключает компьютер при достижении выбранного порога.

## Запуск

Скачайте **GPUShield.exe** из Releases. Python и установка не нужны; требуется драйвер NVIDIA с `nvidia-smi`.
Выберите порог **60–95 °C** (по умолчанию 85), нажмите «Сохранить», затем «Включить».
Окно скроется в трей. Двойной щелчок по значку открывает окно; правый щелчок — меню отключения и выхода.
При каждом запуске требуется ручное включение. Автозапуска с Windows нет.
Для изменения настроек сначала выключите защиту. Порог сохраняется в `%LOCALAPPDATA%\GPUShield\settings.json`.

Раз в секунду считывается температура ядра всех NVIDIA GPU. Если хотя бы одна достигает порога,
отправляется `shutdown /s /f /t 0`. **Несохранённые данные могут потеряться.**
Это программный дополнительный контроль: он зависит от работающего приложения, датчика, Windows и прав на выключение.
В режиме сна он не работает. Порог общий для всех NVIDIA GPU; при разных картах выбирайте меньший подходящий порог.
Hotspot и температура памяти не измеряются. При ошибке датчика открывается окно, чтение повторяется.
AMD и Intel не поддерживаются. Журнал: `%LOCALAPPDATA%\GPUShield\events.log`.
EXE не имеет цифровой подписи. Проверено на RTX 3060; Windows 11 отдельно не тестировалась.

## Рекомендации: 20 самых популярных записей Steam

Источник рейтинга: [Steam Hardware Survey, сентябрь 2026](https://store.steampowered.com/hwsurvey/videocard/),
доступный снимок при проверке 1 ноября 2026. Это выборка пользователей Steam, не доля всех компьютеров мира.
Включены ноутбучные GPU и встроенная графика: поэтому последняя строка не является поддерживаемой картой.

**Порог ниже — рекомендация автора приложения**, а не рекомендация NVIDIA и не заводской предел.
Для настольных RTX с указанным пределом выбран меньший из 85 °C и «предел минус 5 °C».
Для GTX 1650 предложено 85 °C после проверки конкретной платы; для ноутбуков 83 °C — предварительный ориентир,
который обязательно нужно сверить с документацией производителя устройства. Ноутбуки могут штатно работать горячее.
Не увеличивайте порог только ради устранения выключений: сначала проверьте охлаждение и ограничьте FPS.
Приложение само не меняет мощность, частоты и вентиляторы.

## Сборка из исходников

Python 3.12 x64, Windows. Запустите `build.ps1` или выполните:

```powershell
python -m pip install -r requirements.txt
python -m PyInstaller --noconfirm --clean --onefile --windowed --name GPUShield GPUShield.py
```

Результат: `dist/GPUShield.exe`. Файл `profiles.py` должен лежать рядом с исходником при сборке.
Рабочий процесс GitHub Actions собирает EXE на Windows и сохраняет его как артефакт; при теге `v*` публикует релиз.
